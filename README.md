# Apache ZooKeeper: отказоустойчивый координатор

Проект поднимает ансамбль ZooKeeper 3.9.6 из трёх серверов и две копии
координатора расчёта. Он демонстрирует кворум, эфемерные узлы, выбор лидера,
восстановление с чекпоинта и fencing по эпохе.

## Быстрый старт

Требуется Docker Desktop с Compose v2. Java 17 уже находится внутри образа
ZooKeeper; локальная установка Java не нужна.

```bash
cp .env.example .env
make build
make ensemble
make status
make quorum-test
make ephemeral-test
make demo-unfenced
make demo-fenced
make verify
```

Логи сохраняются в `logs/`, результаты и чекпоинт — в `runtime/`. Команды
`demo-unfenced` и `demo-fenced` автоматически приостанавливают текущего лидера
через `SIGSTOP`, ждут публикации результата запасным координатором, затем
возобновляют старого лидера.

Для итоговых прогонов использован реальный экспорт 22 286 уникальных пар из ДЗ №3.
Файл `data/pairs.ndjson` не публикуется из-за размера, но координатор проверяет
число строк и SHA-256 канонического содержимого. Контрольный SHA-256 указан в
отчёте и журналах, поэтому расчёт обеих копий можно проверить независимо.
